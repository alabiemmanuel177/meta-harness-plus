## Phase 1 implications

- 15/33 missing instances are in `django`. If V7's eval-skip pattern carries to V10 unchanged, the same instances will produce empty patches in V10 and skip the grader. V10's Phase 3 agent must have a stronger empty-patch fallback.
- 31/33 have no eval directory — the SWE-bench harness pre-filtered them, almost certainly because the predictions.jsonl entry was empty or un-applyable. This is mostly upstream-of-our-control: the V10 answer is to never submit empty patches in the first place.

**Conclusion:** the missing 33 are dominated by V7's empty-patch submissions (a property of V7's actor, not the sandbox). The sandbox itself does not appear to need additional hardening for these specific repos. Phase 1+ work focuses on improving the actor (Phase 3) and never submitting empty patches (Phase 4 validation gates a non-empty diff before write_predictions).
